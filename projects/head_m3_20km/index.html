Head M3: 火箭头部 20 km / Ma 3 精细仿真

v5 头部局部计算域 0.5 cm 超高分辨率仿真、中等张角脱体激波与激波层干涉结构展示

火箭气动数值模拟项目 head_m3_20km（v5 头部局部计算域、20 km 平流层高度、Mach 3.0 超声速、最细网格 0.5 cm）的几何构型与飞行工况分栏分析、inputs.used 核心参数配置分栏详解及稳态波系演化结果。

一、头部局部构型与飞行工况分栏详解（20 km / Mach 3.0）

1. 20 km 平流层低等温层超声速来流状态

  • 飞行高度与马赫数：20 km，prob.mach = 3.0（处于 v5 头部系列 Ma 2 → Ma 3 → Ma 5 过渡工况），来流沿 +y 方向（0. 1. 0.）
  • 环境静压与静温：prob.p_inf = 5.529e4 dyn/cm²（5.529 kPa），prob.T_inf = 216.65 K
  • 来流速度与气体属性：U_inf = 885 m/s，理想气体比热比 γ = 1.4，摩尔质量 μ = 28.97 g/mol，无粘欧拉模型 do_visc = 0

2. v5 火箭头部局部截取构型（Head-Only）

  • 几何截取策略：加载 0° 收拢构型 rocket.stl（model_v1_0.stl，stl_scale = 0.1 mm→cm，stl_center = 0. 0. 0.），下游出口截断于 y = +64 cm（肩后保留约 0.77 m 箭体），尾部舵面（y > 360 cm）位于域外
  • 前体精细结构：包含头部激波针（针尖 y = -68.6 cm，r: 0 → 12 cm，针根 y = -48.5 cm）、鼻帽过渡段（y = -47 .. -13 cm，r → 100 cm）及肩部凸缘（y = -13 .. -10 cm，r = 112 cm）
  • 前体压差阻力定义：圆柱段侧壁平行于来流并直接穿过超声速出口面，所测 Cd 纯粹表征火箭头部前体压差阻力系数

3. Mach 3 中等张角脱体弓形激波与波系干涉

  • 19.5° 马赫角过渡特征：Ma = 3.0 对应马赫角 arcsin(1/3) = 19.5°，介于 Ma 2（30°）与 Ma 5（11.5°）之间，弓形激波脱体距离与张角呈典型过渡形态
  • 激波脱体与穿出尺度：主脱体弓形激波驻留于 y ≈ -84 cm（激波针尖上游约 16 cm，恰为 Ma 5 的 2 倍、Ma 2 的一半），在 y = +64 cm 出口面处半径扩展至 r ≈ 264 cm
  • 适度加宽计算域：横向计算域由 ±320 cm 扩展至 x, z ∈ [-352, 352] cm（距侧壁保留约 88 cm 净空），确保激波完全由下游出口面无反射穿出

4. 时间尺度与稳态气动收敛特性

  • 全域流经时间：轴向域长 2.56 m 在 885 m/s 来流下特征流经时间约 t_flow = 2.56 / 885 ≈ 2.9 ms
  • 稳态推进时长：算例推进至 plt00597（t = 0.009802 s / 9.80 ms），覆盖约 3.4 倍全域流经时间
  • 气动力单调演化规律：后 25 % 时段前体平均阻力系数稳定于 Cd = 1.418（末值 1.415，脉动幅值 ΔCd = 0.007），在 Ma 2（1.322）与 Ma 5（1.445）之间呈清晰单调递增趋势

二、算例参数配置分栏详解（head_m3_20km/inputs.used）

head_m3_20km/inputs.used 由 tools/run_case.py 组合 v5 common.inputs 与 head_M3_20km/inputs 生成，采用均匀来流冲击启动 + 1.0 ms 渐进过渡保护 + 适配 19.5° 激波张角的五层 AMR 双分区加密（最细 0.5 cm），核心配置分栏如下：

1. 均匀来流冲击启动（Impulsive Start）

  • 初始化模式：prob.init_mode = 0（t = 0 时刻全域初始化为均匀 Mach 3.0 自由来流）
  • 方案优势：避免静止气体启动在钝头前产生慢速亚声速滞止包，直接由前体壁面反射快速建立 y ≈ -84 cm 处的脱体弓形激波

2. v5 启动过渡段渐进保护（Startup Ramp）

  • 1.0 ms 渐进启动窗口：匹配 885 m/s 来流波速设定 cns.startup_time = 1.0e-3 s（1.0 ms，介于 Ma 5 的 0.5 ms 与 Ma 2 的 1.5 ms 之间），期间采用一阶重构（cns.startup_plm_iorder = 1）并将 CFL 由 cns.cfl_start = 0.1 线性爬升至 cns.cfl = 0.3
  • 稳态二阶高精度格式：t ≥ 1.0 ms 自动切换至二阶 PLM 重构（cns.plm_iorder = 2，plm_theta = 1.0 minmod 限制器），开启层间通量修正 do_reflux = 1
  • 小切单元保正保护：tiny_cell_vfrac = 0.2，T_floor = 10.0 K，repair_T_min = 50.0 K

3. STL 嵌入边界高分辨率构建（STL & EB2）

  • 几何文件与坐标：eb2.geom_type = stl，eb2.stl_file = rocket.stl，eb2.stl_scale = 0.1，eb2.stl_center = 0. 0. 0.
  • 0.5 cm 级 EB 参数：eb2.cover_multiple_cuts = 1，eb2.coarse_by_coarsening = 0 各层直接由 STL 独立构建几何，eb2.maxiter = 200，eb2.max_grid_size = 16

4. Mach 3 适度加宽头部计算域与边界（Domain & BCs）

  • 计算域范围：prob_lo = -352. -192. -352.，prob_hi = 352. 64. 352.（cm），物理尺寸 7.04 × 2.56 × 7.04 m，is_periodic = 0 0 0
  • 基础网格划分：amr.n_cell = 88 32 88，保持粗网格单元尺寸 L0 = 8 cm
  • 边界条件配置：cns.lo_bc = 2 1 2（y = -192 cm 自由来流入口 1），cns.hi_bc = 2 2 2（侧壁与 y = +64 cm 超声速零梯度出口 2）

5. 五层 AMR 网格与扩容 tip / head 双分区加密

  • 五层网格分辨率：amr.max_level = 4（ref_ratio = 2 2 2 2），对应 L0–L4 = 8 / 4 / 2 / 1 / 0.5 cm（blocking_factor = 8，max_grid_size = 32，regrid_int = 4，n_error_buf = 2，开启 loadbalance_with_workestimates = 1）
  • tip 针尖核心区（0.5 cm）：[-24, 24] × [-80, -40] × [-24, 24] cm 包裹激波针尖与针根，fill_lev = cut_lev = shock_lev = 4 锁定最细 0.5 cm
  • head 激波层扩容区（1–2 cm）：适配前移至 y ≈ -84 cm 的弓形激波，由 [-136,136]×[-112,0] 扩展为 [-160, 160] × [-128, 0] × [-160, 160] cm，背景 fill_lev = 2（2 cm），壁面与主激波 cut_lev = shock_lev = 3（1 cm）
  • 全局判据与显存控制：区外箭体表面 refine_cutcells_max_lev = 3（1 cm）；外翼激波 refine_shock_max_lev = 2（2 cm，pjump = 0.2）；refine_max_dengrad_lev = 0

6. 采样输出与前体气动力积分（Output & Forces）

  • 推进终止控制：配置目标 stop_time = 0.012 s（实际稳态采样至 plt00597 / 9.80 ms）
  • 流场与检查点频率：amr.plot_per = 2.0e-4 s（每 0.2 ms 输出一帧流场），amr.check_per = 0.002 s（每 2 ms 保存检查点）
  • 前体阻力实时监测：forces.int = 2 持续输出 forces.csv，参考面积 forces.ref_area = 31415.93 cm²（πR²，R = 100 cm）
