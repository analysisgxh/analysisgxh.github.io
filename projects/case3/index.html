Case 3: 火箭 30 km / Ma 5 GPU 仿真

60° 舵面高超声速流场、AMR 显存诊断调优（inputs2 → inputs3）与激波演化展示

火箭气动数值模拟项目 Case 3（30 km 高空、Mach 5 高超声速、60° 气动减速舵面 case3_30km_M5_f60_gpu_inputs3_full08）的算例分栏配置、GPU 显存溢出（OOM）单参数诊断调优、后台运行与后处理脚本以及多物理场/光学流场结果展示。

一、算例背景与几何构型

火箭减速舵面四种展开角 STL 模型对比。Case 3 采用 60° 展开角构型 model_v1_60.stl，来流沿 +y 方向以 Mach 5 入射。

Case 3 对应火箭再入返回段 30 km 高空、Mach 5 的典型高超声速连续流工况（Kn ≈ 2×10⁻⁶，滞止温度约 1360~1480 K，理想气体欧拉模型适用性良好），用于评估大展开角减速舵面在强弓形激波与舵面脱体激波干扰下的气动阻力特性。

二、Case 3 算例配置（inputs3）

cases/case3_30km_M5/inputs3

以下按六大功能模块分栏列出全部核心配置：

1. 自由来流与静止启动（Free Stream & Init）

  • 飞行高度与马赫数：30 km，prob.mach = 5.0，来流方向 +y（0. 1. 0.）
  • 来流静压 / 静温（CGS）：prob.p_inf = 1.2e4 dyn/cm²（1.2 kPa），prob.T_inf = 227.0 K（声速约 302 m/s，来流速度约 1510 m/s）
  • 初始流场模式：prob.init_mode = 1（全域气体静止，由入口施加 Mach 5 来流向下游推进建立流场；高超声速下启动激波可顺利向下游洗出计算域）

2. STL 几何与嵌入式边界（STL & AMReX-EB）

  • 几何文件：eb2.geom_type = stl，eb2.stl_file = rocket.stl（复制自 geometry/model_v1_60.stl）
  • 单位缩放与平移：eb2.stl_scale = 0.1（mm → cm），eb2.stl_center = 0. 40.91 0.（适配 60° 舵面坐标系）
  • 切割单元构建：eb2.cover_multiple_cuts = 1（处理舵面铰链狭缝多重切割），eb2.coarse_by_coarsening = 0（各层直接由 STL 构建）

3. 计算域尺寸与边界条件（Domain & BCs）

  • 计算域范围：x, z ∈ [-1024, 1024] cm，y ∈ [-1024, 2048] cm（总尺度 20.48 × 30.72 × 20.48 m，复用 Case 5 大域将入口前移）
  • 粗网格划分：amr.n_cell = 64 96 64，对应 L0 基础网格间距 32 cm
  • 边界类型：cns.lo_bc = 2 1 2（y = -1024 cm 设为超声速自由来流入口 1），cns.hi_bc = 2 2 2（侧向及下游设为零梯度外流 2）

4. 欧拉格式与小切割单元保护（Solver & Repair）

  • 气体物性：理想气体无粘求解（cns.do_visc = 0，eos_gamma = 1.4，eos_mu = 28.97）
  • 重构与推进：cns.plm_iorder = 2，plm_theta = 1.0（minmod 限制器抑制强激波振荡），cfl = 0.3，开启层间通量守恒修正 do_reflux = 1
  • 小单元温度保护：tiny_cell_vfrac = 0.1，T_floor = 10.0 K，repair_T_min = 50.0 K（防止背风膨胀区切单元非物理低温崩溃）

5. AMR 网格层级与 GPU 负载均衡（AMR & GPU）

  • 4 层网格体系：amr.max_level = 3，ref_ratio = 2 2 2，对应分辨率 L0–L3 = 32 / 16 / 8 / 4 cm
  • 分块与缓冲：blocking_factor = 8，max_grid_size = 32，regrid_int = 4 4 4，n_error_buf = 2 2 2 2，grid_eff = 0.7
  • GPU 内存池与负载：开启工作量估计负载均衡（loadbalance_with_workestimates = 1）；amrex.the_arena_init_size = 536870912（512 MiB 初始池，非显存硬上限）

6. 网格加密区域与输出监测（Refinement & I/O）

  • 表面与固定盒加密：开启切割单元表面加密 refine_cutcells = 1（至 L3：4 cm）；核心固定加密盒 [-256, 256] × [-192, 1280] × [-256, 256] cm
  • 动态判据开关：refine_max_dengrad_lev = 0，refine_shock_max_lev = 0（显存受控关键设置，详见下节）
  • 采样与气动力：plot_per = 5.0e-4 s，check_per = 0.005 s；每 2 步积分气动力至 forces.csv（参考面积 31415.93 cm²）

三、显存诊断分栏对比：inputs2（OOM）vs inputs3（稳定运行）

在 GPU 移植调试中，inputs2 因启动激波触发全计算域大规模细网格导致显存溢出；inputs3 仅修改单个参数即定位并解决了显存瓶颈：

原方案 inputs2：三重加密导致 GPU 显存溢出

同时启用了固定盒加密、火箭表面加密与全域密度差动态加密：

cns.refine_dengrad = 1.8e-7       # 约 1% rho_inf，高度敏感
cns.refine_max_dengrad_lev = 3    # 允许全域触发 L3 (4 cm)

失败机理：Case 3 采用静止气体 + Mach 5 强入口启动，启动波在入口附近形成横跨大面积区域的密度梯度，高敏阈值瞬间触发海量 L3 细网格，在第 8 粗步（t ≈ 6.78×10⁻⁴ s）耗尽显存（GPU OOM）。

改进方案 inputs3：关闭动态标定，全程稳定计算

相对于 inputs2 仅修改一项，关闭密度梯度触发的额外网格增殖：

cns.refine_max_dengrad_lev = 0    # 关闭密度差动态加密
cns.refine_shock_max_lev   = 0    # 压力跳变动态加密同样保持关闭

核心结论：关闭的是“按流场梯度自动追加细网格”，并非关闭求解器的激波捕捉能力——求解器依然在固定加密盒与近壁 4 cm 网格上精确计算强激波，显存占用稳定可控。

inputs3 各区域网格分辨率与激波捕捉效果对照

激波所在区域 实际网格分辨率 对流场与激波捕捉的影响
固定加密盒内部（[-256, 256] × [-192, 1280] × [-256, 256] cm） 最细 4 cm（L3） 完整包络箭体头部弓形激波、60° 舵面激波与近尾迹，高分辨率清晰刻画波系
火箭表面附近（STL 切割单元） 表面加密至 4 cm（L3） 保证壁面压力积分与气动阻力系数 \(C_d\) 计算精度
固定盒外远场区域（\|x\| > 2.56 m） 逐级过渡至 32 cm（L0） 激波仍连续正常传播并顺利穿出外边界，仅远场波面厚度变宽、细节略平滑

四、GPU 两阶段运行与监控流程

采用“先短程启动验证（0.012 s）、再长程稳态推进（设定 stop_time = 0.8）”的两阶段执行方案：

阶段一：短程显存诊断验证（0.012 s）

读取 inputs3 验证启动激波阶段显存稳定性，输出至 case3_30km_M5_f60_gpu_inputs3_trial：

ROOT="$HOME/XiaohuiGao/rocket_cns_v4_gpu/rocket_cns_v4"
EXE="$ROOT/build_gpu/bin/rocket_cns"
OUT="$ROOT/results/case3_30km_M5_f60_gpu_inputs3_trial"

export OMP_NUM_THREADS=1 CUDA_VISIBLE_DEVICES=0
mkdir -p "$OUT"
cp "$ROOT/cases/case3_30km_M5/inputs3" "$OUT/inputs.used"
cp "$ROOT/geometry/model_v1_60.stl" "$OUT/rocket.stl"
cd "$OUT" && "$EXE" inputs.used 2>&1 | tee run.log

阶段二：长程完整计算（full08）

在 tmux 会话中追加 stop_time = 0.8 覆盖原短程时长，保存至独立目录 case3_30km_M5_f60_gpu_inputs3_full08：

OUT="$ROOT/results/case3_30km_M5_f60_gpu_inputs3_full08"
mkdir -p "$OUT"
cp "$ROOT/cases/case3_30km_M5/inputs3" "$OUT/inputs.used"
cp "$ROOT/geometry/model_v1_60.stl" "$OUT/rocket.stl"
printf '\nstop_time = 0.8\n' >> "$OUT/inputs.used"
cd "$OUT" && "$EXE" inputs.used 2>&1 | tee run.log

# 另开终端实时跟踪进度
tail -n 30 -F "$OUT/run.log"

五、后处理

算例生成的 plt* 时间步数据通过以下脚本生成单帧图、总览序列与多物理场 MP4/GIF 视频（make_movie.py 会自动扫描 $R/frames/* 与 $R/summary_frames* 下包含 plt*.png 的直接子目录）：

R="results/case3_30km_M5_f60_gpu_inputs3_full08"

# 1. 生成单张缩放总览图（马赫数、无量纲压力、温度 + Cd 曲线）
python3 tools/plot_case.py "$R" --zoom 0.8 -o "$R/summary_zoom.png"

# 2. 批量生成各物理量与光学流场帧图并导出动画
python3 tools/post/make_frames.py "$R" --vars mach pressure temperature schlieren --jobs 4
python3 tools/post/make_movie.py "$R" --vars mach pressure temperature schlieren

# 3. 逐个 plt 时刻批量生成总览帧图（加 --zoom 0.8 生成近场放大版）并合成 15 fps 视频
OUT="$R/summary_frames_zoom" && mkdir -p "$OUT"
for P in "$R"/plt*; do
  NAME=$(basename "$P")
  [[ "$NAME" =~ ^plt[0-9]+$ ]] && [ -s "$P/Header" ] || continue
  python3 tools/plot_case.py "$R" --plt "$NAME" --zoom 0.8 -o "$OUT/$NAME.png"
done
python3 tools/post/make_movie.py "$R" --vars summary_frames_zoom --fps 15
