Head M5: 火箭头部 30 km / Ma 5 精细仿真

v5 头部局部计算域 0.5 cm 超高分辨率仿真、贴体弓形激波与激波层剪切涡精细解析

火箭气动数值模拟项目 head_m5_30km（v5 头部局部计算域、30 km 平流层高空、Mach 5.0 高超声速、最细网格 0.5 cm，对应 v4 Case 3 头部高分辨率复现）的几何构型与飞行工况分栏分析、inputs.used 核心参数配置分栏详解及稳态波系演化结果。

一、头部局部构型与飞行工况分栏详解（30 km / Mach 5.0）

1. 30 km 平流层高超声速自由来流状态

  • 飞行高度与马赫数：30 km，prob.mach = 5.0（对应 v4 全箭 Case 3 工况的头部超高分辨率算例），来流沿 +y 轴方向（0. 1. 0.）
  • 环境静压与静温：prob.p_inf = 1.2e4 dyn/cm²（1.2 kPa），prob.T_inf = 227.0 K
  • 来流速度与气体属性：U_inf = 1510 m/s，理想气体比热比 γ = 1.4，摩尔质量 μ = 28.97 g/mol，无粘欧拉模型 do_visc = 0

2. v5 火箭头部局部截取构型（Head-Only）

  • 几何截取策略：加载 0° 收拢构型 rocket.stl（model_v1_0.stl，stl_scale = 0.1 mm→cm，stl_center = 0. 0. 0.），下游出口截断于 y = +64 cm（肩后保留约 0.77 m 箭体），尾部舵面（y > 360 cm）置于域外
  • 前体精细结构：包含头部激波针（针尖 y = -68.6 cm，r: 0 → 12 cm，针根 y = -48.5 cm）、鼻帽过渡段（y = -47 .. -13 cm，r → 100 cm）及肩部凸缘（y = -13 .. -10 cm，r = 112 cm）
  • 前体压差阻力定义：圆柱箭体侧壁平行于来流并穿过超声速出口边界，所测 Cd 纯粹表征前体（头部）高超声速压差阻力系数

3. Mach 5 贴体弓形激波与激波层剪切涡特征

  • 11.5° 小马赫角贴体效应：Ma = 5.0 马赫角仅 arcsin(1/5) = 11.5°，脱体弓形激波显著后移贴体，驻留于激波针尖上游约 5–8 cm（y ≈ -73 .. -76 cm，距入口保留约 115 cm 未扰动自由来流）
  • 横向穿出与紧凑盒子：弓形激波在 y = +64 cm 出口面处半径收窄至 r ≈ 232 cm，横向计算域收紧为 x, z ∈ [-320, 320] cm（距侧壁留有约 90 cm 裕度，无侧壁激波反射）
  • 针—帽激波干扰涡结构：0.5 cm 细网格清晰解析出激波针前缘压缩波与钝鼻帽强弓形激波相交诱发的 Kelvin–Helmholtz 不稳定剪切涡列

4. 高波速时间尺度与稳态气动收敛特性

  • 极短流经时间：轴向域长 2.56 m 在 1510 m/s 来流速度下特征流经时间仅 t_flow ≈ 1.7 ms
  • 稳态推进时长：推进至 stop_time = 0.006 s（6.00 ms，plt00533），覆盖约 3.5 倍全域流经时间
  • 气动力收敛精度：t > 1.5 ms 后阻力曲线完全平直，后 25 % 时段前体平均阻力系数稳定于 Cd = 1.445，脉动幅值低至 ΔCd = 0.001

二、算例参数配置分栏详解（head_m5_30km/inputs.used）

head_m5_30km/inputs.used 由 tools/run_case.py 组合 v5 common.inputs 与 head_M5_30km/inputs 生成，采用均匀来流冲击启动 + 0.5 ms 渐进过渡保护 + 五层 AMR 紧凑双分区加密（最细 0.5 cm），核心配置分栏如下：

1. 均匀来流冲击启动（Impulsive Start）

  • 初始化模式：prob.init_mode = 0（t = 0 时刻计算域全域赋值为均匀 Mach 5.0 自由来流）
  • 方案优势：无需等待入口启动激波扫过计算域，直接由前体壁面反射快速建立贴体脱体弓形激波，缩短非定常过渡时间

2. v5 启动过渡段渐进保护（Startup Ramp）

  • 0.5 ms 快速启动窗口：匹配 1510 m/s 高波速（气流约 4 次扫过 60 cm 头部区），设定 cns.startup_time = 5.0e-4 s（0.5 ms），期间强制采用一阶迎风重构（cns.startup_plm_iorder = 1）并将 CFL 由 cns.cfl_start = 0.1 线性提升至 cns.cfl = 0.3
  • 稳态二阶高精度重构：t ≥ 0.5 ms 自动切换至二阶 PLM 重构（cns.plm_iorder = 2，plm_theta = 1.0 minmod 限制器），开启粗细界面通量重分配 do_reflux = 1
  • 小切单元保正修复：tiny_cell_vfrac = 0.2，T_floor = 10.0 K，repair_T_min = 50.0 K

3. STL 嵌入边界高分辨率构建（STL & EB2）

  • 几何文件与坐标：eb2.geom_type = stl，eb2.stl_file = rocket.stl，eb2.stl_scale = 0.1，eb2.stl_center = 0. 0. 0.
  • 0.5 cm 级 EB 参数：eb2.cover_multiple_cuts = 1，eb2.coarse_by_coarsening = 0 各层直接由 STL 精确构建几何，eb2.maxiter = 200，eb2.max_grid_size = 16 降低细层 EB 内存占用

4. Mach 5 紧凑头部计算域与边界（Domain & BCs）

  • 计算域范围：prob_lo = -320. -192. -320.，prob_hi = 320. 64. 320.（cm），物理尺寸 6.40 × 2.56 × 6.40 m（相比 Ma = 2 横向收窄 23 %），is_periodic = 0 0 0
  • 基础网格划分：amr.n_cell = 80 32 80，对应粗网格单元尺寸 L0 = 8 cm
  • 边界条件配置：cns.lo_bc = 2 1 2（y = -192 cm 自由来流入口 1），cns.hi_bc = 2 2 2（侧壁与 y = +64 cm 超声速零梯度出口 2）

5. 五层 AMR 网格与紧凑 tip / head 双分区加密

  • 五层网格分辨率：amr.max_level = 4（ref_ratio = 2 2 2 2），对应 L0–L4 = 8 / 4 / 2 / 1 / 0.5 cm（blocking_factor = 8，max_grid_size = 32，regrid_int = 4，n_error_buf = 2，开启 loadbalance_with_workestimates = 1）
  • tip 针尖核心区（0.5 cm）：[-24, 24] × [-80, -40] × [-24, 24] cm 包裹激波针尖与针根，fill_lev = cut_lev = shock_lev = 4 锁定最细 0.5 cm
  • head 紧凑激波层区（1–2 cm）：随激波贴体收紧至 [-136, 136] × [-112, 0] × [-136, 136] cm，背景 fill_lev = 2（2 cm），鼻帽/肩部表面与主激波 cut_lev = shock_lev = 3（1 cm）
  • 全局判据与显存约束：区外箭体表面 refine_cutcells_max_lev = 3（1 cm）；外翼弓形激波 refine_shock_max_lev = 2（2 cm，pjump = 0.2；测试表明若升至 L3 在 t = 0.4 ms 即超 900 万网格并突破 15 GB 显存）；refine_max_dengrad_lev = 0

6. 高频采样输出与前体阻力积分（Output & Forces）

  • 推进终止控制：stop_time = 0.006 s（max_step = 10000000）
  • 流场与检查点频率：amr.plot_per = 1.0e-4 s（每 0.1 ms 输出一帧流场），amr.check_per = 0.001 s（每 1 ms 保存检查点）
  • 前体阻力实时监测：forces.int = 2 持续输出 forces.csv，参考面积 forces.ref_area = 31415.93 cm²（πR²，R = 100 cm）
